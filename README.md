# AFK Tweaks releases

Installers for AFK Tweaks, a Windows gaming tweak launcher. Download the newest `AFK-Setup-<version>.exe` from [Releases](https://github.com/NeaRRivalz/afk-releases/releases/latest).

Installed copies update themselves: `update.json` in each release is signed, and AFK only installs updates that carry that signature and match its hash.
