# Afterclutch releases

Installers for Afterclutch (formerly AFK Tweaks), a Windows gaming tweak launcher. Built for the clutch. Download the newest `AFK-Setup-<version>.exe` from [Releases](https://github.com/NeaRRivalz/afk-releases/releases/latest).

Installed copies update themselves: `update.json` in each release is signed, and Afterclutch only installs updates that carry that signature and match its hash.
